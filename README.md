# Dsource Coffee Shop

A coffee shop website designed to showcase Dsource's coffee menu, company information, reservations, gallery, and contact details.

## 📌 About the Project

**Dsource Coffee Shop** is a responsive coffee shop website created using HTML, CSS, Tailwind CSS, and Font Awesome.

The website provides customers with information about the coffee shop, available drinks, reservation options, photos, and contact information.

## ✨ Features

* Coffee shop landing page
* Navigation menu
* Hero section
* About Dsource section
* Coffee menu
* Reservation form
* Photo gallery
* Contact section
* Footer navigation
* Responsive styling
* Font Awesome icons
* Tailwind CSS utilities

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Custom styling through `styles.css`
* **Tailwind CSS** – Utility-based styling
* **Font Awesome 5.15.3** – Icons for calendar, clock, and location

## 🏠 Website Sections

### 1. Home

The home section introduces visitors to Dsource Coffee Shop with the message:

> Welcome to Dsource Coffee Shop

It also includes a short description and an **Explore Our Menu** button.

### 2. About Dsource

The About section describes Dsource as a cozy place for coffee lovers.

It highlights:

* Handcrafted coffee
* Artisan pastries
* Different coffee varieties
* Comfortable atmosphere
* A place for work, conversation, and relaxation

### 3. Menu

The menu section displays three coffee products:

* **Caramel Macchiato**
* **Americano**
* **Frappuccino**

Each menu item contains an image, name, and description.

### 4. Reservations

The reservation section provides a form where customers can enter:

* Name
* Email
* Phone number
* Date
* Time
* Additional message

The form also uses Font Awesome icons for the calendar and clock fields.

### 5. Gallery

The gallery displays four coffee shop images:

These images are arranged using the website's image-grid styling.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `styles.css` are in the same folder.
4. Place all image files in the correct location.
5. Open `index.html` in a browser.

For easier development, you can use the **Live Server** extension in Visual Studio Code.

## ⚠️ Notes

* The website depends on the Tailwind CSS CDN for Tailwind utility classes.
* The website also depends on the Font Awesome CDN for icons.
* The reservation form does not currently have a backend connection.
* The contact form does not currently send messages to a database or email service.
* Image filenames must match the paths used in the HTML.
* The main custom styling is stored in `styles.css`.
